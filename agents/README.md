# Agent guidance

This directory contains reusable engineering guidance for AI-assisted work. It
complements the repository's contribution and engineering documents; those
documents remain authoritative if guidance overlaps or conflicts.

## Index

- [Commands](commands.md): development, verification, and focused checks.
- [Knowledge base](knowledge-base.md): general workflow for exploring and changing a codebase.
- [Rules](rules/README.md): concise practices organized by topic.

Load only the guidance relevant to the current task. Keep guidance concise,
actionable, and free of rules that merely restate existing canonical documents.
