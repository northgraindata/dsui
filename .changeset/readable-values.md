`KeyValue` labels identifier keys (`dagId` reads "DAG ID"), shows booleans as Yes or No, joins lists, and shows zoned timestamps in the user's time zone and clock with the exact value on hover. A table column can ask for the same date format with `format: "datetime"`.

"Clear all" appears only when a table is sorted or filtered, and a resource tree without a selection no longer marks every unlinked node as selected.
