> **Developer Preview**
>
> DSUI is under active development. Expect breaking changes, incomplete adapter coverage, and bugs.

DSUI is an open-source, extensible platform for your data stack. Connect tools, install plugins, and build custom capabilities tailored to your infrastructure.

![DSUI workspace overview showing connected data and infrastructure services](https://dsui.northgraindata.com/assets/product.png)

## Start here

[Run DSUI with npx](/docs/getting-started/quickstart) and connect an in-memory
DuckDB workspace in a few minutes. Choose Docker when you need isolation or are
already running the rest of your stack in Compose.

![DSUI infrastructure overview showing services converging on one workspace](/docs/assets/dsui-runtime-overview.png)

## Extend your data stack

Connect databases, orchestration tools, transformation services, and storage
through adapters. Install plugins to add capabilities across connected services.

- Declare adapter sources and service connections in `dsui.yaml`
- Run service operations on the server and keep credentials there
- Build custom integrations with the [Adapter SDK](/docs/adapter-sdk/overview)
- Build pages, actions, jobs, and workflows with the [Plugin SDK](/docs/plugin-sdk/overview)

The [configuration guide](/docs/getting-started/configuration) includes complete
examples for loading adapters and connecting services.

## Current status

- Local-first, self-hosted Developer Preview
- Partial adapter coverage
- Breaking changes between preview releases are possible
- Enterprise features and hosted control planes are not included yet
