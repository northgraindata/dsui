dsui is one lightweight, local-first interface for the services in a developer data stack. Start with [Getting Started](/docs/getting-started), or go directly to [Docker Compose](/docs/docker-compose).

## What v0.1 covers

- Trino queries and metadata
- Kafka topics, messages, groups, ACLs, schemas, and Kafka Connect
- S3 and MinIO buckets, objects, previews, and downloads
- Snowflake, BigQuery, Redshift, PostgreSQL, and Databricks data workflows
- Apache Airflow, Dagster, and dbt Cloud operational workflows
- UI-managed and declarative connections
- Public community adapters distributed as pinned npm bundles or pinned GitHub commits
