## Setup

Connect to dbt Cloud with an API token.

```yaml
services:
  - id: dbt
    adapter: dbt
    name: dbt
    connection:
      method: cloud
      baseUrl: https://cloud.getdbt.com
      accountId: ${DBT_ACCOUNT_ID}
      apiToken: ${DBT_API_TOKEN}
```

Connect to a local dbt project when DSUI runs through the native or npx runtime.

```yaml
connection:
  method: local
  projectPath: /data/dbt
  target: dev
```

### Docker limitation

The official Docker image does not include a dbt runtime. If an adapter requires
an executable or runtime, provide it in the image used to run DSUI.

## Available

- Projects and jobs for dbt Cloud
- Runs, run details, logs, and run artifacts
- Models, columns, and lineage
- Sources and tests
- Semantic models, metrics, and saved queries
- Local dbt commands through `execute` and `build`

## Not yet available

- Full parity with the dbt Cloud UI
- Coverage outside the current branch scope
