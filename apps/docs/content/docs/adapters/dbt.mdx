## Setup

Connect to dbt Cloud with an API token.

```yaml
services:
  - id: dbt
    adapter: dbt
    name: dbt
    connection:
      method: cloud
      baseUrl: https://cloud.getdbt.com
      accountId: ${DBT_ACCOUNT_ID}
      apiToken: ${DBT_API_TOKEN}
```

Connect to a dbt Core or Fusion project on the DSUI host. This is supported by
the npx/native runtime, which can execute the host's `dbt` or `dbt-fusion`
binary.

```yaml
connection:
  method: local
  projectPath: /data/dbt
  target: dev
```

### Docker limitation

The official Docker image does not bundle dbt Core or dbt Fusion. A Docker
container also cannot execute a macOS or Windows `dbt` binary mounted from the
host. Use `npx dsui` for local dbt projects, or build a custom image that
contains the matching dbt runtime and project files.

## Available

- Projects and jobs for dbt Cloud
- Runs, run details, logs, and run artifacts
- Models, columns, and lineage
- Sources and tests
- Semantic models, metrics, and saved queries
- Local dbt commands through `execute` and `build`

## Not yet available

- Full parity with the dbt Cloud UI
- Coverage outside the current branch scope
