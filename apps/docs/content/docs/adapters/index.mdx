An adapter is the integration layer between DSUI and one service. It provides
the connection details, data resources, actions, and pages that make that
service useful inside the shared workspace.

DSUI is designed to bring several kinds of systems together:

- Databases and query engines
- Orchestration and scheduling
- Transformation and modeling
- Object storage and file services
- Infrastructure and operational tools
- Private services built with the Adapter SDK

Preview coverage is partial, not complete support. Each adapter page lists what is available and what is not.

Built-in adapters are only the starting point. Community and private adapters
can extend the same workspace without requiring DSUI to know every service in
advance. See the [Adapter SDK](/docs/adapter-sdk) if you need to connect a
service that is not in this catalog.

The catalog is intentionally a compact starting point. Adapter coverage is
preview-level and varies by service; check each adapter page before relying on a
workflow in a production environment.
