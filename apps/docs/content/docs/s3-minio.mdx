---
title: S3 / MinIO
description: Configure object storage browsing, previews, metadata, and downloads.
---

## Connection

```yaml
services:
  - id: storage
    adapter: s3
    connection:
      endpoint: http://minio:9000
      region: us-east-1
      forcePathStyle: true
      accessKeyId: ${MINIO_ACCESS_KEY}
      secretAccessKey: ${MINIO_SECRET_KEY}
```

## Capabilities

Buckets, prefixes, objects, metadata, bounded text/image previews, and streamed downloads.

## Authentication

Static keys and standard AWS credential resolution are supported server-side.

## Limitations

Multipart uploads, lifecycle administration, and IAM management are outside v0.1.

## Troubleshooting

Enable `forcePathStyle` for typical local MinIO installations and verify the bucket region.
