---
title: CLI
description: Run the dsui server binary directly.
---

```text
dsui
dsui serve
dsui version
dsui doctor
dsui adapter-host --bundle <path>
```

`serve` (the default) starts the HTTP server and static web bundle.
`doctor` validates the configuration file and reports whether each
configured adapter resolves. `adapter-host` runs one verified adapter
bundle in an isolated subprocess; the server invokes it, humans
normally do not.

Connections belong in the UI or `dsui.yaml`; there are no `add`,
`connect`, or `configure` commands.
