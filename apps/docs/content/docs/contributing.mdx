title: Contributing
description: Make a focused change and verify it before opening a pull request.
---

Read the [contribution guide](https://github.com/northgraindata/dsui/blob/main/CONTRIBUTING.md) before you start.

Follow the contribution guide for repository boundaries, change scope, and
verification expectations.

```bash
bun install --frozen-lockfile
bun run check
bun run build
```

Keep a pull request focused. Add tests for behavior changes and update the docs when a public contract changes.

For an adapter, start from the [Adapter SDK](/docs/adapter-sdk/overview). Validate the connection, keep credentials server-side, and state the coverage and limitations explicitly.

The [complete example adapter](https://github.com/northgraindata/dsui/tree/main/examples/example-adapter)
shows package setup, tests, local loading, resources, actions, pages, and
optional browser components. Use it as the practical starting point for a new
adapter.
