You can contribute with code, documentation, reproductions, or manual testing. You don't need an AI tool or a chat account. The full rules are in [CONTRIBUTING.md](https://github.com/northgraindata/dsui/blob/main/CONTRIBUTING.md).

<Steps>
<Step>

### Pick an issue

Browse [good first issues](https://github.com/northgraindata/dsui/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22) for a bounded change, or [help wanted](https://github.com/northgraindata/dsui/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22help%20wanted%22) for broader work. Comment on the issue before you start, so maintainers can confirm the scope.

</Step>
<Step>

### Set up the repository

Fork and clone the repository, use the Bun version that `package.json` pins, and start the development servers:

```bash
bun install --frozen-lockfile
bun run dev
```

</Step>
<Step>

### Make one focused change

Reproduce the problem first, and add a test for a behavior change. Keep the pull request to one purpose, and update the docs when a public contract changes. Name the branch `<type>/dsui-<number>-<short-description>`, such as `fix/dsui-123-wrap-long-values`, using the Linear ID that the GitHub issue shows.

</Step>
<Step>

### Run the checks

```bash
bun run format:check
bun run lint
bun run typecheck
bun run test
bun run build
```

While you work, run the scripts of the package that you changed. For a documentation change, run the docs checks from `apps/docs`: `lint`, `test`, `typecheck`, `build`, and `check:links`.

</Step>
<Step>

### Open a pull request

Use the template. Describe the problem, the new behavior, and the checks that you ran, and add `Fixes #<github-issue-number>` and `Fixes DSUI-<linear-id>`. Include screenshots for a visible change.

</Step>
</Steps>

## Where to make a change

| Area | Directory |
| --- | --- |
| Product UI | `apps/web` |
| Server and runtime | `packages/server` |
| Adapter contracts and adapter components | `packages/adapter-sdk` |
| Official integrations | `packages/adapter-*` |
| Plugins and plugin contracts | `packages/plugin-*` |
| Website and documentation | `apps/site`, `apps/docs` |

## Build an extension

To add an integration, start with the [Adapter SDK](/docs/adapter-sdk/overview) and its [tutorial](/docs/adapter-sdk/tutorial). To extend the whole workspace, see the [Plugin SDK](/docs/plugin-sdk/overview). The [example adapter](https://github.com/northgraindata/dsui/tree/main/examples/example-adapter) shows a complete package.

## Report a problem

Report a vulnerability through [SECURITY.md](https://github.com/northgraindata/dsui/blob/main/SECURITY.md). Everyone who takes part agrees to the [Code of Conduct](https://github.com/northgraindata/dsui/blob/main/CODE_OF_CONDUCT.md).
