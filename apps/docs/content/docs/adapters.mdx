## Available

Snowflake ships as the default adapter. Every adapter, default
included, resolves by package name through the same loader: local
packages import in-process, pinned npm packages install verified and
run isolated in an `adapter-host` subprocess. No adapter id receives
special handling anywhere in the server.

```yaml
services:
  - id: analytics
    adapter: snowflake
    name: Analytics warehouse
    connection:
      accountIdentifier: org-account
      token: ${SNOWFLAKE_TOKEN}
```

## Model

An adapter declares metadata, a connection schema, resources (data),
actions (behavior), pages (composition), and stores (state). dsui owns
all browser UI. Adapters cannot ship React, HTML, CSS, or browser
JavaScript.

Reads require `inspect`, mutations require `execute`. The SDK carries
no per-item authorization metadata, so this convention is the
contract.

## Community packages

Community adapters are third-party server code. Production sources
must be immutable and integrity-pinned; verified bundles execute in an
isolated subprocess with no access to the server process. See
[Adapter SDK](/docs/adapter-sdk) for the template and manifest format.
