> **Recommended path: npx**
>
> The npx runtime is the shortest way to try DSUI on a local machine. It reads
> `dsui.yaml` from your project directory and keeps local state in your user
> data directory.

Start with the [npx quickstart](/docs/getting-started/quickstart), or read the
[installation guide](/docs/getting-started/installation) if you want to compare
the npx and Docker runtimes first.

When you are ready to connect an existing stack, continue to
[configuration](/docs/getting-started/configuration).
