## Choose a runtime

Use npx for local development and host tools such as dbt:

```bash
npx dsui
```

Use Docker when you want an isolated, reproducible deployment. The Docker
image does not provide the host's dbt executable; see the [installation
guide](/docs/getting-started/installation) for the boundary between the two
runtime modes.

## 1. Create `dsui.yaml`

```yaml
services:
  - id: warehouse
    adapter: duckdb
    name: Analytics warehouse
    connection:
      method: file
      path: /data/warehouse.duckdb
```

## 2. Create `compose.yaml`

```yaml
services:
  dsui:
    image: ghcr.io/northgraindata/dsui:latest
    ports:
      - "4192:4192"
    environment:
      DSUI_CONFIG: /etc/dsui/dsui.yaml
    volumes:
      - ./dsui.yaml:/etc/dsui/dsui.yaml:ro
      - dsui-data:/data

volumes:
  dsui-data:
```

## 3. Start DSUI

```bash
docker compose up -d
```

## 4. Open the workspace

Open `http://localhost:4192`.

## Expected result

DSUI opens with the **Analytics warehouse** service. Open it, go to **Query**, run `select 42 as answer`, and see one row with `42`.

This example uses DuckDB because it needs no external database. The same
`services` configuration model supports PostgreSQL, Airflow, dbt, S3, and other
adapters. Continue to [configuration](/docs/getting-started/configuration) when
you are ready to connect an existing stack.
