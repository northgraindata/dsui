## Image

Release images are published to `ghcr.io/northgraindata/dsui` for `linux/amd64` and `linux/arm64`. Each `vX.Y.Z` tag publishes a version-specific tag (for example, `0.1.0`) and updates `latest` for stable releases. Pin a version in production; use `latest` when you want the newest stable release.

```bash
docker run --read-only --tmpfs /tmp -p 4192:4192 \
  -v dsui-data:/data ghcr.io/northgraindata/dsui:0.1.0
```

The image listens on port `4192`, runs without root privileges, and requires only `/data` to be writable. Mount declarative configuration read-only at `/etc/dsui/dsui.yaml`. Never mount the Docker socket.

To create a release, push a semantic version tag such as `v0.1.0` to a commit already on `main`. CI validates the app and Docker image before publishing the image and creating GitHub Release notes.

DSUI is an open-source project, and its GHCR image is intended to be public so it can be pulled without signing in. GitHub creates new container packages as private by default, so after the first release, change the package visibility to **Public** once in the package settings. GitHub does not allow changing a public package back to private.
